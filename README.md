## 项目简介

在 LTE 终端射频一致性 / 产线测试中，测试仪器会为每个样机、每种双工方式（FDD / TDD）
导出包含大量测试项的 XML 结果文件。人工从这些 XML 中挑选出各频段的最大输出功率与
ACLR 数据、再逐格填入 Excel 报告，既繁琐又容易出错。

**本工具将这一流程自动化：**

1. 选择一个包含所有 XML 结果文件的文件夹；
2. 程序按命名规范自动识别样机编号（1#、2#、3#…）与测试类型（FDD/TDD）；
3. 解析 XML，抽取各频段的功率与 ACLR 指标；
4. 将数据写入内置（或自定义）的 Excel 模板，生成最终报告。

工具采用 **WPF（.NET 10）** 开发，为单文件自包含发行，最终用户无需安装 .NET 运行时。
Excel 读写通过直接操作 `.xlsx`（OpenXML / ZIP + XML）实现，**不依赖任何第三方 Excel 库**。

## 功能特性

- 📁 **文件夹批量扫描**：无需逐个选择文件，选择文件夹后自动扫描全部 XML。
- 🔢 **任意数量样机**：支持 1#、2#、3#、4#… 自动识别与排序。
- 🧠 **智能命名识别**：基于正则 `^(\d+)#\s*(FDD|TDD)\.xml$`（大小写不敏感）自动分类。
- 👁️ **实时预览**：扫描后即时列出样机编号、测试类型与文件名，并给出统计。
- 📊 **多指标提取**：最大输出功率（5MHz / 10MHz）+ ACLR（E-UTRA / UTRA1 / UTRA2，±方向）。
- 🎯 **多频段覆盖**：Band 1/2/3/4/5/7/8/12/13/17/18/19/20/25/26/28/34/38/39/40/41/66。
- 🧩 **模板可替换**：内置 Base64 模板；若存在自定义模板文件则优先使用。
- 🛡️ **健壮的回退策略**：功率数据按 RB 配置多级回退取值，尽量避免空缺。
- 🖥️ **单文件绿色发行**：自包含单 exe，双击即用。

## 使用步骤

1. **准备 XML 文件**：把所有 XML 结果文件放到同一个文件夹，并按下文规范命名。
2. **启动程序**：双击 `LTEoutpoweraclrToExcelTool.exe`（或从 VS/命令行调试运行）。
3. **选择文件夹**：点击「选择文件夹」，选中包含 XML 的目录。
4. **查看扫描结果**：程序自动列出所有识别到的样机与文件，底部状态栏显示统计。
5. **生成报告**：点击「生成 Excel 报告」，选择保存位置与文件名（默认 `LTE_Report_yyyyMMdd_HHmm.xlsx`）。
6. **核对数据**：打开生成的 Excel，确认各样机各频段数据填充正确。

> 若缺少 1# 或 2# 样机数据，程序会弹出提示，说明数据将如何映射到表格列，可选择继续或取消。

## XML 文件命名规范

文件名必须匹配正则：`^(\d+)#\s*(FDD|TDD)\.xml$`（大小写不敏感）。

| 规则 | 说明 |
|------|------|
| 格式 | `{编号}# {类型}.xml` |
| 编号与 `#` | 之间**无空格**（如 `1#`） |
| `#` 与类型 | 之间可有空格（推荐一个空格，如 `1# FDD`） |
| 类型 | 必须为 `FDD` 或 `TDD` |

**正确示例**

```
1# FDD.xml   1# TDD.xml
2# FDD.xml   2# TDD.xml
3# FDD.xml   3# TDD.xml
```

**错误示例**

```
1-FDD.xml    ✗ 分隔符错误
FDD1.xml     ✗ 顺序错误
1# LTE.xml   ✗ 类型非 FDD/TDD
```

## 数据处理说明

### 提取的指标

生成的报告包含每个频段、每个样机的以下指标：

- **最大输出功率**：5MHz 与 10MHz 两种带宽，各含 Low / Mid / High 三个信道点。
- **ACLR**：E-UTRA、UTRA ACLR1、UTRA ACLR2 三类，每类含 `+` 与 `−` 两个方向。

### XML 解析逻辑（`LteExcelFiller.ParseXml`）

- 遍历 XML 中的 `TestItemList`，根据 `ListContext` 判断测试项类别：
  - `Maximum Output Power ... @ Band{n}` → 最大输出功率
  - `Adjacent Channel Leakage Power Ratio ... @ Band{n}` → ACLR
- 从每个 `TestItem` 的 `Condition` 中用正则解析信道 `ULCH`、带宽 `BW`、资源块 `UL_MOD_RB`、
  资源块位置 `RB_Pos`，并读取 `MeasValue`。
- 对同一组 (信道, 带宽, RB, 位置, 描述) 只取**首次出现**的值，避免重复。

### 功率取值的多级回退策略（`Parse_MaxPower`）

为兼容不同测试脚本导出的 RB 配置，取值按优先级回退：

- **5MHz**：优先 `RB=8, RB_Pos=LOW` → 回退 `RB=25` → 任意位置 `RB=8`（优先 LOW）→ 任意 RB（优先 25、8）。
- **10MHz**：优先 `RB=50, RB_Pos=LOW` → 回退 `RB=12` → 任意位置 `RB=50`（优先 LOW）→ 任意 RB（优先 50、12）。
- 若仅识别到 1 个信道，则用该值同时填充 Low/Mid/High（兼容合并单元格）。

### Excel 写入

- **内置模板**：以 Base64 字符串嵌入源码，无需外部文件即可生成报告（`WriteAllDataMulti`，当前面向 1#/2# 两样机布局）。
- **自定义模板**：若模板文件存在，则读取该文件并使用 `WriteAllDataUserTemplate`（支持 1#–4# 样机），
  同时通过 `RemoveSample34Rows` 清理未使用的 3#/4# 行。
- 写入方式为直接解析 `.xlsx`（ZIP 包内的 sheet XML），按 `BandStartCol` 映射定位单元格列，
  按预定义行布局写入功率与 ACLR 值——**不依赖任何 Office/Excel 组件**。

### 频段 → 起始列映射（`BandStartCol`）

每个频段占用 3 个连续列（Low / Mid / High）：

```
Band1→G  Band2→J  Band3→M  Band4→P  Band5→S  Band7→V  Band8→Y
Band12   Band13   Band17   Band18   Band19   Band20   Band25
Band26   Band28   Band66   Band34   Band38   Band39   Band40   Band41
```

## 常见问题（FAQ）

**Q：提示“未找到符合命名规范的 XML 文件”？**
A：检查命名是否匹配 `{编号}# {类型}.xml`；`#` 后建议有一个空格，类型须为 FDD/TDD。

**Q：扫描到的文件数量不对？**
A：确认所有 XML 在同一文件夹；避免大小写重复（如同时存在 `1# FDD.xml` 与 `1# fdd.xml`）。

**Q：生成的 Excel 没有数据？**
A：确认 XML 含有效测试数据、格式正确、文件未损坏或为空。

**Q：有 3 个以上样机，但内置模板只显示 2 个？**
A：内置模板面向 1#/2# 布局，会优先使用 1#、2# 数据。要显示更多样机，请提供支持 3#/4# 的自定义模板，
或分批处理。

**Q：程序启动后立即退出？**
A：可能触发了有效期校验（见上）——请检查系统时间是否正确，或使用较新的构建版本。
